# 🧠 Computer Quiz Game

A simple Python quiz game that tests your computer knowledge.

The game asks multiple questions about computer hardware and checks your answers using **Fuzzy Matching** with the `RapidFuzz` library, allowing small spelling mistakes while still recognizing correct answers.

---

## 🚀 Features

- Interactive command-line quiz.
- Uses Fuzzy Matching to compare answers.
- Accepts answers with small spelling mistakes.
- Calculates the final score.
- Shows answer similarity percentage.

---

## 🛠️ Technologies Used

- Python 🐍
- RapidFuzz Library
- String Matching Algorithm
